When we receive any new dataset, the first steps involve a quick inspection to understand its structure and quality. We begin by checking the shape to see the number of rows and columns, followed by head() to preview the first few entries. It’s essential to examine the data types of each column to ensure they match the expected formats (like integers, floats, strings, etc.). We also check for null or missing values to determine if any data cleaning is required. Identifying duplicate rows is important to maintain the integrity of the dataset. Additionally, we assess whether the dataset contains statistical anomalies or outliers, and we use basic descriptive statistics (like mean, median, min, max, and standard deviation) to understand how the data looks mathematically. These steps help build a strong foundation for further analysis or modeling.
